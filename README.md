# Movie Finder
Movie Finder is a website application that allows users to search for movies and view other details about them. The website integrates the OMDb (Open Movie Database) API to provide real-time movie data.

---

## API Used
**OMDb (Open Movie Database)**  
- **API Documentation:** [https://www.omdbapi.com/](https://www.omdbapi.com/)  
- **Functionality:** Users can search for movies by title. The API returns detailed information about the movie in real time.  
- **API Key:** A free API key is required to access the OMDb API.  

---

## Features
1. **Home Page**  
   - Introduces the service and explains the purpose of the website.
   - Includes a navigation menu that allows users to easily move between pages.  

2. **Search Page**  
   - Allows users to search for movies by title.  
   - Retrieves live data from the OMDb API.  
   - Displays movie details including poster, title, release date, genre, actors, directors, plot, and IMDb ratings.  

3. **Contact Page**  
   - Users can send a message through a simple form with fields: Name, Email, and Message.  
   - Validation prevents blank submissions.  

4. **Group Members Page**  
   - Presents all team members along with their roles, photo, short bios or fun facts.
